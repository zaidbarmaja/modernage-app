# عصر الحداثة — لوحة تحكم مدير النظام (Admin Dashboard)

لوحة تحكم ويب متكاملة لمدير النظام (الحساب الأساسي)، مبنية بـ **HTML + CSS + JavaScript صرف (ES Modules)** مع **Firebase** — على **نفس قاعدة بيانات التطبيق** (مشروع `mohmeed-kadim`). كل ما تفعله اللوحة يظهر فوراً في تطبيق الجوال والعكس.

الواجهة عربية بالكامل (RTL) بهوية «عصر الحداثة» الزيتونية/الكريمية.

---

## ماذا تستطيع اللوحة أن تفعل؟

يدخل مدير النظام بحسابه الأساسي فيتحكّم بكل شيء تقريباً مثل التطبيق:

| القسم | الميزات |
|------|---------|
| **📊 نظرة عامة** | مؤشرات شاملة: المشاريع، المواقع، الموظفون، الزبائن، الحاضرون اليوم، العقود (الكلي/المحصّل/المتبقّي)، وأحدث النشاطات. |
| **🏗️ المشاريع والمواقع** | مشاريع التصميم ومواقع التنفيذ: إضافة/تعديل/حذف، إسناد مصمم/منفّذين، ربط زبون، العقد المالي، المهام والملاحظات، والتقارير والوصولات المرتبطة. |
| **📝 التقارير** | التقارير اليومية للموظفين + تقارير التنفيذ بالصور، مع فلاتر (الموظف/الفترة). |
| **👆 البصمة والحضور** | كل سجلات الحضور، ملخّص الساعات (عمل/إضافي/تأخير)، فلترة بالموظف والتاريخ، وروابط خرائط لموقع البصمة. |
| **💰 المالية** | عقود المشاريع، الوصولات الإلكترونية (قبض/صرف)، السلف والصرفيات، مع فلترة بالتاريخ. |
| **👥 المستخدمون** | إنشاء حساب موظف/زبون، تعديل، تغيير الصلاحية/القسم، إعادة تعيين كلمة المرور، تفعيل/تعطيل، عرض الحضور، والحذف النهائي. |
| **🔔 الإشعارات** | بثّ إشعار لكل المستخدمين وعرض كل الإشعارات. |
| **⚙️ إعدادات الشركة** | موقع البصمة المعتمد + نطاقه، وأوقات الدوام الموحّدة. |

## بيانات الدخول

الدخول باسم وكلمة مرور ثابتين (نفس التطبيق تماماً)، قابلة للتغيير من **`js/config.js`**:

```js
export const APP_LOGIN = {
  username: "mo_3g",          // اسم الدخول
  password: "YOUR_ADMIN_PASSWORD",    // كلمة المرور
};
```

خانة **«تذكّرني»** تُبقيك مسجّلاً على نفس الجهاز حتى تضغط «تسجيل الخروج».

## التشغيل محلياً

⚠️ **مهم:** اللوحة تستخدم **ES Modules**، لذا **لا تفتح `index.html` بنقرة مزدوجة** (بروتوكول `file://` يمنع تحميل الوحدات — خطأ CORS). افتحها عبر خادم محلي (http).

### الأسهل (ويندوز)
انقر نقراً مزدوجاً على **`تشغيل-اللوحة.bat`** — يشغّل خادماً محلياً ويفتح المتصفح على `http://localhost:8010`. أبقِ النافذة السوداء مفتوحة.

### بدائل من الطرفية
```bash
python -m http.server 8010      # ثم افتح http://localhost:8010
# أو
npx serve .
```

### متطلب Firebase (مرّة واحدة)
يجب أن يكون **Email/Password** مفعّلاً في مشروع Firebase (وهو مفعّل أصلاً للتطبيق و modage):
Authentication ← Sign-in method ← Email/Password ← Enable.

## النشر على الإنترنت (اختياري)

أي استضافة ثابتة تكفي (Firebase Hosting / Netlify / GitHub Pages). مثال بـ Firebase:
```bash
firebase deploy --only hosting
```
> على الاستضافة (https) تعمل كل الميزات بما فيها إنشاء الحسابات وتحديد الموقع.

## بنية الملفات

| الملف | الوظيفة |
|------|---------|
| `index.html` | الهيكل: شاشة الدخول + الشريط الجانبي والمحتوى |
| `styles.css` | كل التنسيق والهوية البصرية (RTL) |
| `js/firebase.js` | تهيئة Firebase ونقطة الاتصال بالـ SDK |
| `js/config.js` | بيانات دخول مدير النظام (قابلة للتغيير) |
| `js/auth.js` | تسجيل الدخول/الخروج وجلسة Firestore |
| `js/utils.js` | تنسيق، تسميات، تنبيهات، نوافذ، تجزئة كلمات المرور |
| `js/data.js` | طبقة الوصول لـ Firestore + إنشاء الحسابات |
| `js/store.js` | مخزن بيانات لحظي مشترك بين الصفحات |
| `js/ui.js` | مساعدات بناء الواجهة |
| `js/app.js` | الموجّه (Router) ونقطة الدخول |
| `js/pages/*.js` | صفحات اللوحة (نظرة عامة، مشاريع، تقارير، بصمة، مالية، مستخدمون، إشعارات، إعدادات) |

## ملاحظات

- الحسابات المُنشأة من اللوحة تعمل مباشرةً في تطبيق الجوال (نفس آلية التجزئة والبريد الداخلي).
- كلمات المرور تُخزَّن **مجزّأة بأمان** (SHA-256 + ملح + تمطيط ١٢٠٠٠ مرّة) في مجموعة `credentials` المنفصلة — لا تُحفظ كنص.
- إنشاء الحسابات وتحديد الموقع يحتاجان سياقاً آمناً (خادم محلي `http://localhost` أو استضافة `https`) — وهو ما يوفّره المشغّل.
- هذه اللوحة مخصّصة لمدير النظام؛ لوحة المحاسبة المالية المنفصلة موجودة في مجلد `modage`.
