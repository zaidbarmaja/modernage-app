# عصر الحداثة — تطبيق إدارة التصميم والتنفيذ الهندسي

تطبيق Flutter متعدّد الأدوار لشركة «عصر الحداثة»، مبني على Firebase
(المصادقة + Firestore + التخزين)، وبواجهة عربية كاملة (RTL) بألوان الشعار.

## الأدوار والمزايا
1. **البصمة (الدخول/الخروج بالموقع)** — للموظفين:
   - المدني 7ص–3ع، المعماري 10ص–6م، والجمعة عطلة.
   - حساب عدد أيام الدوام، ساعات التغيّر، والساعات الإضافية.
2. **موظف التصميم** — تسجيل دخول بالموقع + إدراج المشاريع يدوياً
   (صاحب المشروع، التفاصيل، نوع العرض، الأيام المتبقية، المبلغ المتبقي).
3. **موظف التنفيذ** — تسجيل الدخول للموقع عبر GPS مع إشعار للإدارة،
   المستندات والملاحظات، الصور اليومية، خطة الأيام القادمة ومدّتها،
   والسلف والصرفيات.
4. **المحاسبة** — صفحتا التصميم والتنفيذ، الدخول لصفحة كل موظف وبصمته،
   وميزانية كل زبون.
5. **الإدارة** — متابعة المشاريع حسب التصميم وإضافة مواقع العمل للتنفيذ.
6. **الزبون** — كامل تفاصيل مشاريعه وميزانيته.

## التشغيل
> الخطوة الإلزامية: ربط Firebase. اتبع الدليل الكامل في
> **[SETUP_FIREBASE_AR.md](SETUP_FIREBASE_AR.md)**.

باختصار:
```bash
flutterfire configure   # يولّد lib/firebase_options.dart
flutter pub get
flutter run
```

## بنية المشروع
```
lib/
  core/        الثوابت، الألوان/الثيم، أدوات التنسيق
  models/      نماذج البيانات (Firestore)
  services/    المصادقة، Firestore، الموقع، التخزين
  widgets/     عناصر واجهة مشتركة
  screens/     الشاشات حسب الدور (auth, attendance, design, execution,
               accounting, admin, customer)
```
