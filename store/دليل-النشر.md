## ⛔ ثلاثة أشياء توقف الرفع — لازم تُحَل أولاً

### ١) سياسة الخصوصية غير منشورة على رابط عام

جوجل تطلب **رابطاً عاماً** يفتحه أي شخص. فحصتُ الاستضافة:

- الموقع موجود: `https://mohmeed-kadim.web.app`
- لكن `/privacy/` **لا يعرض سياسة الخصوصية** — يعرض واجهة النظام المحاسبي، لأن
  `modage/firebase.json` فيه تحويل شامل (`rewrites`) يرجّع `index.html` لأي مسار.

**الحل** (خطوتان):

1. انسخ مجلد سياسة الخصوصية إلى مجلد الاستضافة:
   ```
   DASHBORD/privacy/  ←  انسخه إلى  →  modage/privacy/
   ```
   (ملفان فقط: `index.html` و`logo.png`. الملفات الحقيقية لها أولوية على التحويل الشامل،
   فسيعمل الرابط.)

2. انشر الاستضافة من مجلد `modage`:
   ```bash
   firebase deploy --only hosting --project mohmeed-kadim
   ```

   > ⚠️ هذا الأمر يستبدل الموقع المنشور بالكامل بمحتوى مجلد `modage` المحلي.
   > تأكّد أن نسختك المحلية هي الأحدث قبل التنفيذ.

3. تأكّد أن الرابط يفتح فعلاً: `https://mohmeed-kadim.web.app/privacy/`

هذا هو الرابط الذي تضعه في Play Console.

**بديل أسرع إن ما تريد تلمس الاستضافة:** ارفع `index.html` على أي استضافة مجانية
(GitHub Pages مثلاً) واستخدم رابطها.

### ٢) لقطات الشاشة — لازم تصوّرها بنفسك

جوجل تطلب **٢ على الأقل** (والأفضل ٤–٨). المطلوب: PNG أو JPEG، الضلع بين ٣٢٠ و٣٨٤٠ بكسل.

خذها من هاتف حقيقي أو محاكي:

```bash
flutter run --release
# ثم صوّر الشاشة من الهاتف (Power + Volume Down)
```

**اللقطات المقترحة بالترتيب:**
1. شاشة الدخول
2. شاشة البصمة/الحضور
3. قائمة المشاريع أو المواقع
4. تفاصيل مشروع
5. شاشة الإشعارات
6. شاشة التقارير

> 💡 لا تضع بيانات زبائن حقيقية في اللقطات — استخدم حساباً تجريبياً بأسماء وهمية.

ضعها في `store/graphics/screenshots/`.

### ٣) حساب تجريبي للمراجعين (مهم جداً)

تطبيقك **لا يفتح بدون تسجيل دخول**، ومراجع جوجل لا يستطيع الدخول → **رفض شبه مؤكد**.

في Play Console ← **App content** ← **App access** ← اختر
«All or some functionality is restricted» وأدخل:

- اسم المستخدم وكلمة المرور لحساب **موظف تجريبي** أنشأته من الداشبورد
- تعليمات مختصرة بالإنجليزية، مثال:

  > The app requires a login. Use the demo credentials above.
  > Enter the username in the "الاسم" field and the 4-digit code in the password field.
  > All content is in Arabic (RTL). Attendance requires location permission, which is
  > requested only when the user taps the check-in button.

> ⚠️ **لا تعطهم حساب المدير.** أنشئ حساب موظف تجريبي بصلاحيات محدودة وبيانات وهمية،
> واتركه فعّالاً طوال فترة المراجعة.

## ⏱️ مهم قبل ما تبدأ: قاعدة الـ ١٢ مختبِراً

إذا حساب المطوّر عندك **شخصي** (Personal) ومُنشأ بعد تشرين الثاني ٢٠٢٣، جوجل تُلزمك بـ:

- إجراء **اختبار مغلق (Closed testing)** بـ **١٢ مختبِراً على الأقل**
- يبقون مشتركين **١٤ يوماً متواصلة**
- ثم تتقدّم لطلب الوصول للإنتاج (Production access)

يعني **أسبوعان إضافيان** قبل ما يظهر التطبيق للعامة. خطّط لها من الآن — اجمع ١٢ إيميل
Gmail (موظفينك مثلاً) من اليوم الأول.

حسابات **الشركات (Organization)** معفاة من هذا الشرط. إذا شركتك مسجّلة رسمياً، سجّل
حساب مؤسسة بدل شخصي — يوفّر عليك أسبوعين.

## 🔐 إجابات نموذج Data safety

انسخها كما هي.

**هل يجمع التطبيق أو يشارك أياً من أنواع البيانات المطلوبة؟** → **نعم**

**هل البيانات مشفّرة أثناء النقل؟** → **نعم** (كل الاتصالات عبر Firebase بـ HTTPS)
**هل يستطيع المستخدم طلب حذف بياناته؟** → **نعم** (عبر `support@modernage.online`، مذكور في سياسة الخصوصية)

| نوع البيانات | يُجمع؟ | يُشارَك؟ | الغرض | إلزامي؟ |
|---|---|---|---|---|
| الاسم | نعم | لا | تشغيل التطبيق + إدارة الحساب | إلزامي |
| رقم الهاتف | نعم | لا | تشغيل التطبيق + إدارة الحساب | إلزامي |
| معرّفات المستخدم (User IDs) | نعم | لا | تشغيل التطبيق + إدارة الحساب | إلزامي |
| الموقع التقريبي | نعم | لا | تشغيل التطبيق (التحقّق من موقع الحضور) | إلزامي |
| الموقع الدقيق | نعم | لا | تشغيل التطبيق (التحقّق من موقع الحضور) | إلزامي |
| الصور | نعم | لا | تشغيل التطبيق (إرفاق الوصولات والتقارير) | اختياري |
| الملفات والمستندات | نعم | لا | تشغيل التطبيق | اختياري |
| معرّفات الجهاز (Device IDs) | نعم | لا | تشغيل التطبيق (رمز الإشعارات FCM) | إلزامي |

**ملاحظات مهمة عند التعبئة:**
- **لا** تؤشّر «Analytics» ولا «Advertising or marketing» لأي نوع — التطبيق لا يستخدمهما.
- **لا** تؤشّر «Data shared with third parties» — Firebase مزوّد خدمة يعالج البيانات
  نيابةً عنك، وهذا لا يُعدّ مشاركة حسب تعريف جوجل.
- كلمات المرور تُحفظ **مجزّأة (hash + salt)** — لا تُصرَّح ضمن البيانات المجموعة.
- البصمة/Face ID تتم بالكامل على الجهاز عبر نظام التشغيل — **لا تُجمع ولا تُصرَّح**.

## 🔄 التحديثات القادمة

قبل كل تحديث، ارفع رقم الإصدار في `pubspec.yaml`:

```yaml
version: 1.0.1+2      # الرقم بعد + (versionCode) لازم يزيد وإلا يرفض المتجر
```

ثم:
```bash
flutter analyze
flutter build appbundle --release
```

**لا تفقد `android/app/upload-keystore.jks` أبداً** — بدونه لا تستطيع رفع أي تحديث
لنفس التطبيق. خذ منه نسخة احتياطية في مكان آمن.
